# Jordan Avery — Portfolio

A responsive React portfolio built with Vite, custom CSS, and Lucide icons.

## Run locally

1. Install [Node.js](https://nodejs.org/) if it is not already installed.
2. Open this folder in VS Code.
3. In the integrated terminal, run:

   ```bash
   npm install
   npm run dev
   ```

4. Open the local URL printed by Vite (usually `http://localhost:5173`).

Create a production build with `npm run build`, or preview it using `npm run preview`.

## Before publishing

The included name, biography, contact address, social links, education, experience, skills, and projects are illustrative demo content. Update the `profile`, `projects`, `journey`, and `skills` data in `src/App.jsx` and the page metadata in `index.html` with your own details. The project demo/source links currently use example destinations. The contact form opens a prefilled email draft in the visitor's email app; it does not send mail through a server.
